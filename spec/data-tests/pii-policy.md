# PII Policy

## PII Classes
email_content, calendar_content, financial_data, location_data, health_data, contact_data, browsing_history, personal_preferences, long_term_goals

## Rules
- No PII in traces without redaction
- No PII in cloud telemetry
- No PII in evidence packages without redaction
- User can view/delete all PII
- PII encrypted at rest
