# ADR-011: Admin Console

## Status: ACCEPTED

## Rationale
Next.js admin dashboard with RBAC is consistent with ADR-002 (Next.js for frontend). Role-based access with ABAC for fine-grained control. Agent should implement admin screens per spec/ui/screens/enterprise_admin.yaml.

## Decision
Next.js admin dashboard with role-based access.

## Features
- Member management
- Policy configuration
- Audit log viewer
- Model/tool governance
- Budget allocation
- Data residency settings
