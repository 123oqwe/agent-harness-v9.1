 # Factory Agent Role Definitions

 These 17 `.md` files define **factory worker roles**, NOT product specifications.
 They are consumed by `factory/FACTORY_MANUAL.md` to assign Codex/Claude workers
 to implementation tasks. They do NOT belong to the product architecture.

 Do NOT treat these as normative spec. They are factory configuration.
 Product architecture specs live in `spec/architecture/`.
 Product contracts live in `spec/contracts/`.
 This directory is here because the factory shares the spec tree for discovery.
