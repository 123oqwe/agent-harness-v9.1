# Role: Qa

## Responsibilities
- test execution
- coverage
- mutation testing

## Allowed Paths
- tests/

## Forbidden Paths
- requirements/
- contracts/

## Approval Authority
test pass/fail only

## Escalation Rules
- P0 blocker: escalate to CTO Orchestrator immediately
- P1 blocker: escalate within 1 hour
- Specification conflict: stop, report blocked, do not guess
