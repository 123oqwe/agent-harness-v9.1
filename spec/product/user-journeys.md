# User Journeys

Each journey includes: trigger, goal, input, data_used, routing_decisions, RunPlan, models, tools, skills, agent_topology, context_topology, approval_points, user-visible_states, failure_states, evidence, memory_write_proposal, privacy_behavior, success_metrics.

See spec/evals/<domain>/ for domain-specific eval cases and spec/product/jobs-to-be-done.md for the job list. Domain specs are distributed (see SPECIFICATION_INDEX.yaml domains section).
