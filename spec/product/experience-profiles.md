# Experience Profiles

Profiles control UI complexity and default behavior:

## Simple
- Shows: result, status, necessary approvals
- For: General Personal Assistant users
- Hides: Router internals, ReWOO, Context Topology

## Advanced
- Shows: plan, model, tools, budget, run plan summary
- For: Developers, knowledge workers

## Debug
- Shows: Router decisions, trace, state, evidence, fallback
- For: Engineers debugging the system
