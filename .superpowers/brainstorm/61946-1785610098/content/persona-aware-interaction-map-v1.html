发起者 / 公司Owner公司是否接近目标？哪里需要我？全局经营、组织、任务、证据和上下文元数据定目标、跨部门调度、接管、批准、停止公司层全量 + 部门/项目按需钻取显示存在、责任人和风险；敏感原文需目的性解锁
部门负责人本部门承诺什么？资源是否够？本部门全部；上游目标；跨部门依赖摘要拆任务、分配岗位、批准部门动作、接管成员继承公司约束，管理部门上下文，发布验证成果其他部门只显示接口、截止、依赖和责任人
任务成员我今天交付什么？被什么阻塞？自己的任务；协作任务必要内容；个人 Agent执行、请求帮助、委托 Agent、提交成果、交接任务包 + 授权部门片段 + 私有草稿看不到无关项目、预算、人事和敏感客户原文
审计 / 外部专家我需要判断什么？证据完整吗？限定对象、时间窗、证据和必要上下文评论、要求证据、出具意见；通常不能执行只读审查包，不继承日常部门记忆脱敏、限时、可水印；下载和再分享受限
Agent 执行者目标、边界、下一步和停止条件是什么？能力令牌允许的最小任务上下文执行、产证、升级；不能自扩权编译后的 Context Package，带版本和来源被拒绝时只获知缺少能力，不暴露隐藏内容
任务发起者 ≠ 公司Owner
普通成员发起任务，只能看该任务和必要依赖；不能因此获得整个部门或公司的内容。
负责人 ≠ 执行者
负责人对结果负责，可把岗位交给人或 Agent；执行者只得到完成任务所需的最小上下文。
看见 ≠ 可以修改
Owner 可以看到跨部门状态，但具体规范、证据或审计记录仍有独立写权限和审批链。
